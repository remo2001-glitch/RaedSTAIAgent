# اختبارات رائد الأساسية

تشغيل الكل من جذر المستودع:

    bash tests/runall.sh

بثلاث بذور (كما قبل كل دمج):

    for N in 0 7 21; do PYTHONHASHSEED=$N bash tests/runall.sh; done

- بلا pytest — كل ملف `test_*.py` يطبع PASS/FAIL، و`runall.sh` يجمعها ويخرج بخطأ إن فشل شيء.
- لا تحتاج شبكة ولا Redis ولا مفاتيح (BOT_TOKEN=x تلقائياً).
- كل دفعة جديدة تضيف فحوصها هنا.

| الملف | ما يغطيه |
|---|---|
| test_00_imports | ترجمة كل الملفات واستيراد كل الوحدات |
| test_10_event_risk | سقف الأحداث 70%/50%/100% ونافذة ما بعد الصدور |
| test_20_access_guard | الأوامر المخفية، الإغراق، الحد اليومي، تنقية الأخطاء، المجموعات |
| test_30_wallet_auto | مراكز القياس المستقلة، 60/40، بوابات الشراء/Short، سطر المسح |
| test_40_signal_display | الخروج 60/40، تسمية الاتجاه، تمريرة الاتساق |
| test_50_data_liquidity | شموع UTC ولقطة الدفتر المشوّهة |
| test_60_plans_reports | الخطط، التقرير الدوري، المراجعة الأسبوعية، /start، المجدول |
